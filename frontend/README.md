# SlotFinder Frontend

Next.js 14 static site for searching university timetables. Runs entirely client-side using sql.js.

## Setup

```bash
cd frontend
npm install
```

## Development

```bash
npm run dev
# Opens at http://localhost:3000
```

## Building

```bash
npm run build
# Static export in out/
```

## Testing

```bash
npm test           # Run once
npm run test:watch # Watch mode
```

## How It Works

1. On mount, `loadDB("/timetable.db")` fetches the pre-built SQLite bundle
2. `sql.js` loads it into an in-memory database
3. All search/filtering happens client-side via SQL queries
4. Three views: **Timetable** (by section), **Teachers** (by name/code), **Rooms** (by code)

## Key Files

| File | Purpose |
|------|---------|
| `lib/db.ts` | sql.js loader + query helpers |
| `lib/search.ts` | Client-side teacher index builder |
| `lib/constants.ts` | Day/semester constants |
| `app/page.tsx` | Root page, state management |
| `components/timetable/` | Section picker, day view, class cards |
| `components/search/` | Teacher and room search |
| `components/ui/` | Bottom nav, day tabs, SW register |
| `public/timetable.db` | SQLite bundle (generated by backend) |

## Tech Stack

- Next.js 14 (static export)
- React 18
- Tailwind CSS
- sql.js (in-browser SQLite)
- Vitest + Testing Library
